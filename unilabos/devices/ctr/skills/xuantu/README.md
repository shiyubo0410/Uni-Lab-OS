## 2. Modbus 功能码说明

| 功能码 | 名称 | 用途 | 说明 |
|--------|------|------|------|
| 01 (0x01) | 读线圈 | 读取开关量状态 | 运行状态、真空状态等 |
| 03 (0x03) | 读保持寄存器 | 读取数值参数 | 速度、时间、加速度等 |
| 05 (0x05) | 写单个线圈 | 控制开关量 | 使能、真空、启停等 |
| 06 (0x06) | 写单个保持寄存器 | 设置数值参数 | 速度、时间等 |

### 写线圈命令特殊说明

写线圈命令（功能码05）需要发送**一对命令**：
- **置位命令**（FF 00）：开启/触发上升沿
- **复位命令**（00 00）：关闭/触发下降沿

两条命令组合完成一次完整操作，间隔建议 **200ms**。

## 10. CRC16-Modbus 校验算法

### Python 实现

```python
def crc16_modbus(data):
    """
    计算 Modbus CRC16 校验码
    
    Args:
        data: 字节列表，如 [0x01, 0x03, 0x00, 0x10, 0x00, 0x01]
    
    Returns:
        CRC16 值（16位整数）
    """
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 0x0001:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc

# 使用示例
data = [0x01, 0x03, 0x00, 0x10, 0x00, 0x01]
crc = crc16_modbus(data)
crc_low = crc & 0xFF      # 低字节
crc_high = (crc >> 8) & 0xFF  # 高字节
```

## 11. 标准操作流程

### 11.1 单步旋涂流程

```
1. 连接设备（9600→19200）
2. 发送使能命令（置位→复位）
3. 发送真空命令（置位→复位）
4. 设置参数（可选）：
   - 写速度：01 06 A0 DA XX XX CRC CRC
   - 写时间：01 06 A0 DB XX XX CRC CRC
   - 写加速度：01 06 A0 DC XX XX CRC CRC
5. 发送旋涂命令（置位→复位）
6. 查询运行状态，等待完成
```

### 11.2 多步旋涂流程

```
1. 连接设备（9600→19200）
2. 发送使能命令
3. 发送真空命令
4. 设置多步参数（第1-100步）
5. 发送多步旋涂命令
6. 查询运行状态和当前步骤
```
