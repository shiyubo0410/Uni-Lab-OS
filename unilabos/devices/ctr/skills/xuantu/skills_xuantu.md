# 旋涂仪连接与控制技能文档

## 概述

本文档提供旋涂仪（Spin Coater）的完整连接与控制指南，基于 Modbus RTU 通信协议。

## 一、硬件连接

### 1.1 串口参数

| 参数 | 值 |
|------|-----|
| 串口协议 | RS232 |
| 串口号 | COM6 |
| 站号 | 1 |
| 波特率 | 19200 |
| 校验方式 | EVEN |

| 停止位 | 1位 |

### 1.2 特殊连接流程

**重要**：连接时需要先用9600波特率建立连接，再切换到19200

```python
# 连接步骤

2. 确认串口打开成功
3. 将波特率切换到19200
4. 开始正常通信
```

## 二、Modbus 功能码

| 功能码 | 名称 | 说明 |
|--------|------|------|
| 01 (0x01) | 读线圈 | 读取开关量状态（运行状态、真空状态等） |
| 03 (0x03) | 读保持寄存器 | 读取数值参数（速度、时间、加速度等） |
| 05 (0x05) | 写单个线圈 | 控制开关量（使能、真空、启停等） |
| 06 (0x06) | 写单个保持寄存器 | 设置数值参数（速度、时间等） |

### 2.1 写线圈命令特殊说明

写线圈命令（功能码05）需要发送**一对命令**：
- **置位命令**（FF 00）：开启/触发
- **复位命令**（00 00）：关闭/复位

两条命令组合完成一次完整操作，间隔建议200ms。

## 三、常用命令速查

### 3.1 设备控制命令

| 操作 | 命令（16进制） |
|------|----------------|
| 使能开启 | `01 05 00 10 FF 00 8D FF` → `01 05 00 10 00 00 CC 0F` |
| 使能状态查询 | `01 01 00 1F 00 01 CC 0C` |
| 开启真空 | `01 05 00 32 FF 00 2D F5` → `01 05 00 32 00 00 6C 05` |
| 真空状态查询 | `01 01 60 00 00 01 E3 CA` |
| 真空显示值 | `01 03 00 DC 00 01 45 F0` |
| 手动回原 | `01 05 00 14 FF 00 9D CF` → `01 05 00 14 00 00 DC 0F` |

### 3.2 单步运行命令

| 操作 | 命令（16进制） |
|------|----------------|
| 单步启停 | `01 05 00 07 FF 00 3D FB` → `01 05 00 07 00 00 7C 0B` |
| 单步运行状态 | `01 01 00 01 00 01 AC 0A` |
| 读单步速度 | `01 03 A0 DA 00 01 87 F1` |
| 写单步速度 | `01 06 A0 DA XX XX CRC CRC` |
| 读单步时间 | `01 03 A0 DB 00 01 D6 31` |
| 写单步时间 | `01 06 A0 DB XX XX CRC CRC` |
| 读单步加速度 | `01 03 A0 DC 00 01 67 F0` |
| 写单步加速度 | `01 06 A0 DC XX XX CRC CRC` |

### 3.3 多步运行命令

| 操作 | 命令（16进制） |
|------|----------------|
| 多步启停 | `01 05 00 07 FF 00 3D FB` → `01 05 00 07 00 00 7C 0B` |
| 多步运行状态 | `01 01 00 02 00 01 5C 0A` |
| 多步总运行时间 | `01 03 00 48 00 01 04 1C` |
| 多步运行步骤 | `01 03 00 5C 00 01 44 18` |

### 3.4 多步参数设置（第N步）

| 参数 | 读命令 | 写命令 |
|------|--------|--------|
| 速度 | `01 03 A0 E4 00 01 E6 3D` (第1步) | `01 06 A0 E4 XX XX CRC CRC` |
| 时间 | `01 03 A0 E5 00 01 B7 FD` (第1步) | `01 06 A0 E5 XX XX CRC CRC` |
| 加速度 | `01 03 A0 E6 00 01 47 FD` (第1步) | `01 06 A0 E6 XX XX CRC CRC` |

**地址计算**：第N步的地址 = 基础地址 + (N-1) × 3

## 五、CRC16-Modbus 校验

### 5.1 计算算法

```python
def crc16_modbus(data):
    """
    计算 Modbus CRC16 校验码
    
    Args:
        data: 字节列表，如 [0x01, 0x03, 0x00, 0x10, 0x00, 0x01]
    
    Returns:
        CRC16 值（16位整数）
    """
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 0x0001:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc

# 使用示例
data = [0x01, 0x03, 0x00, 0x10, 0x00, 0x01]
crc = crc16_modbus(data)
crc_low = crc & 0xFF      # 低字节
crc_high = (crc >> 8) & 0xFF  # 高字节
```

### 5.2 命令格式

完整命令 = 数据部分 + CRC低字节 + CRC高字节

## 六、标准操作流程

### 6.1 单步旋涂流程

```
步骤1: 连接设备（9600→19200）
步骤2: 发送使能命令（置位→复位）
步骤3: 发送真空命令（置位→复位）
步骤4: 设置参数（可选）
       - 写速度
       - 写时间
       - 写加速度
步骤5: 发送旋涂命令（置位→复位）
步骤6: 查询运行状态，等待完成
```

### 6.2 多步旋涂流程

```
步骤1: 连接设备（9600→19200）
步骤2: 发送使能命令
步骤3: 发送真空命令
步骤4: 设置多步参数（第1-100步）
步骤5: 发送多步旋涂命令
步骤6: 查询运行状态和当前步骤
```

## 七、Python 控制类

### 7.1 基础使用

```python
from scripts.spin_coater_controller import SpinCoaterController
import time

# 创建控制器实例
controller = SpinCoaterController(port='COM6', baudrate=19200, station=1)

# 连接设备
if controller.connect():
    print("设备已连接")
    
    # 使能设备
    controller.enable()
    time.sleep(0.5)
    
    # 开启真空
    controller.vacuum_on()
    time.sleep(0.5)
    
    # 设置参数
    controller.set_single_step_speed(5000)
    controller.set_single_step_time(2000)
    controller.set_single_step_acceleration(5000)
    
    # 启动旋涂
    controller.single_step_start_stop()
    
    # 等待完成
    while controller.single_step_running_status():
        print("运行中...")
        time.sleep(1)
    
    print("旋涂完成！")
    
    # 断开连接
    controller.disconnect()
```

### 7.2 关键方法说明

| 方法 | 功能 |
|------|------|
| `connect()` | 连接设备（自动处理9600→19200切换） |
| `disconnect()` | 断开连接 |
| `enable()` | 使能设备 |
| `enable_status()` | 查询使能状态 |
| `vacuum_on()` | 开启真空 |
| `vacuum_status()` | 查询真空状态 |
| `vacuum_display()` | 读取真空显示值 |
| `manual_home()` | 手动回原 |
| `single_step_start_stop()` | 单步启停 |
| `single_step_running_status()` | 单步运行状态 |
| `multi_step_start_stop()` | 多步启停 |
| `multi_step_running_status()` | 多步运行状态 |
| `set_single_step_speed(speed)` | 设置单步速度 |
| `set_single_step_time(time)` | 设置单步时间 |
| `set_single_step_acceleration(acc)` | 设置单步加速度 |
| `set_multi_step_speed(step, speed)` | 设置多步速度 |
| `set_multi_step_time(step, time)` | 设置多步时间 |
| `set_multi_step_acceleration(step, acc)` | 设置多步加速度 |

## 八、故障排除

### 8.1 连接问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法连接 | 串口号错误 | 检查设备管理器确认COM口号 |
| 无法连接 | 串口被占用 | 关闭其他使用串口的程序 |
| 无法连接 | 设备未上电 | 检查设备电源 |
| 无响应 | 波特率错误 | 确认使用19200波特率 |
| 无响应 | 站号错误 | 确认站号为1 |

### 8.2 命令执行问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 命令无响应 | 设备未使能 | 先发送使能命令 |
| 旋涂不启动 | 真空未开启 | 先开启真空 |
| 参数设置失败 | 超出范围 | 检查参数是否在允许范围内 |
| 状态查询失败 | 通信超时 | 增加超时时间或检查连接 |
