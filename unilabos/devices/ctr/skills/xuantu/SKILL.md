# 旋涂仪 Modbus RTU 协议技能包

## 概述

本技能包提供旋涂仪（Spin Coater）的完整 Modbus RTU 协议文档，支持单步/多步旋涂控制、真空控制、对中控制、摆动控制等功能。

## 设备串口配置

```yaml
串口协议: RS232
串口号: COM6
站号: 1
波特率: 19200
校验方式: EVEN
数据位: 8位
停止位: 1位
特殊连接流程: 先用9600建立连接，再切换到19200
```

## 支持的协议

### 1. Modbus RTU
- 标准 Modbus RTU 协议
- 支持功能码: 01, 03, 05, 06
- CRC16-Modbus 校验
- 波特率: 19200

### 2. 写线圈特殊说明
- 功能码05需要发送命令对（置位+复位）
- 置位: FF 00（触发上升沿）
- 复位: 00 00（触发下降沿）
- 两条命令间隔建议200ms

## 快速开始

### 使能设备

```
置位: 01 05 00 10 FF 00 8D FF
复位: 01 05 00 10 00 00 CC 0F
```

### 开启真空

```
置位: 01 05 00 32 FF 00 2D F5
复位: 01 05 00 32 00 00 6C 05
```

### 单步旋涂启停

```
置位: 01 05 00 07 FF 00 3D FB
复位: 01 05 00 07 00 00 7C 0B
```

### 设置单步速度（示例：5000）

```
写命令: 01 06 A0 DA 13 88 CRC CRC
（13 88 = 5000 的十六进制表示）
```

## CRC16-Modbus 校验

### Python 实现

```python
def crc16_modbus(data):
    """
    计算 Modbus CRC16 校验码
    
    Args:
        data: 字节列表，如 [0x01, 0x03, 0x00, 0x10, 0x00, 0x01]
    
    Returns:
        CRC16 值（16位整数）
    """
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 0x0001:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc

# 使用示例
data = [0x01, 0x03, 0x00, 0x10, 0x00, 0x01]
crc = crc16_modbus(data)
crc_low = crc & 0xFF      # 低字节
crc_high = (crc >> 8) & 0xFF  # 高字节
```

## 标准操作流程

### 单步旋涂流程

```
1. 连接设备（9600→19200）
2. 发送使能命令（置位→复位）
3. 发送真空命令（置位→复位）
4. 设置参数（可选）：
   - 写速度：01 06 A0 DA XX XX CRC CRC
   - 写时间：01 06 A0 DB XX XX CRC CRC
   - 写加速度：01 06 A0 DC XX XX CRC CRC
5. 发送旋涂命令（置位→复位）
6. 查询运行状态，等待完成
```

### 多步旋涂流程

```
1. 连接设备（9600→19200）
2. 发送使能命令
3. 发送真空命令
4. 设置多步参数（第1-100步）
5. 发送多步旋涂命令
6. 查询运行状态和当前步骤
```
