## 4. 科星场景指令集

> **适用范围**: 2-48路产品全兼容  
> **协议格式**: 帧头 + 功能码 + 地址 + 控制位 + 使能位 + 时间 + 结束

### 4.1 协议解析

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧头 | 2字节 | CC DD |
| 功能码 | 1字节 | A3/A4/A5/A6/D3/D5/F3 |
| 地址 | 1字节 | 01 (设备地址) |
| 控制位 | 6字节 | S6 S5 S4 S3 S2 S1 |
| 使能位 | 6字节 | E6 E5 E4 E3 E2 E1 |
| 时间 | 2字节 | TH TL (单位ms) |
| 结束 | 2字节 | DD CC |

**功能码说明**:

| 功能码 | 功能 |
|--------|------|
| A3 | 常开/常闭控制 |
| A4 | 顺序导通 |
| A5 | 顺序断开 |
| A6 | 倒序断开 |
| D3 | 点动脉冲 |
| D5 | 延迟断开 |
| F3 | 反转 |

**控制位/使能位说明**:

- 每个字节8个BIT对应8路继电器
- S1/E1: 1-8路
- S2/E2: 9-16路
- S3/E3: 17-24路
- S4/E4: 25-32路
- S5/E5: 33-40路
- S6/E6: 41-48路

**控制位**: 1=导通/执行动作, 0=断开  
**使能位**: 1=执行对应操作, 0=保持原状

### 4.11 增强继电器控制指令 - A2

**适用范围**: 全系产品

**格式**:

| 帧头 | 功能码 | 地址 | 控制单元数量 | 数据组 | 校验 |
|------|--------|------|--------------|--------|------|
| CC DD | A2 | 01 | N | Num STY TH TL ... | CH CL |

**数据组格式** (每组4字节):

| 字段 | 说明 |
|------|------|
| Num | 第几路继电器 |
| Sty | 动作形式 (0=断开, 1=导通, 2=点动, 3=延迟) |
| TH TL | 时间 (单位10ms, 高位在前) |

**校验**:
- CH = 功能码 + 使能位相加和低8位
- CL = CH + CH 低8位

**控制回复**: `OK!`

### 4.13 读取模拟量数值 - D0

**读取指令**: `CC DD D0 01 00 00 0D CC DD` (固定指令)

**返回格式**:

| 帧头 | 功能码 | 地址 | 模拟量数据(16字节) | 校验 |
|------|--------|------|-------------------|------|
| EE FF | D0 | 01 | D0 D1 ... D14 D15 | CH CL |

**数据解析**:
- D0 D1: 第1路模拟量 (高字节在前)
- 数值 = 实际值 × 100
- 示例: 0x03 0x23 = 803 → 实际值 8.03

## 5. 字符串协议

> **说明**: 所有字符均为英文字符

### 5.1 控制指令格式

**格式**: `"Axx":BCDDDD`

| 字段 | 说明 |
|------|------|
| Axx | 继电器Key (A01-A99) |
| B | SubType (1=常开/常闭, 2=点动, 3=延时, 4=互锁) |
| C | 状态 (0=断开, 1=导通) |
| DDDD | 时延(秒)，不足4位补0 |

### 5.2 控制指令示例

## 6. 心跳ID协议

### 6.1 心跳解读

**连上服务器后，硬件端发送心跳**:

| 字段 | 长度 | 值 | 说明 |
|------|------|-----|------|
| 指令头 | 1字节 | A5 | 固定 |
| 指令长 | 2字节 | H L | 整个命令字节长度 |
| 指令 | 2字节 | 59 4A | 心跳指令 |
| 硬件MacID | 12字节 | XXXXX | 12位设备ID |
| 效验码 | 1字节 | X | 前面所有字节相加和取低字节 |

**12字节ID生成规则**:
- 由设备MAC地址演变而来
- MAC地址对应的ASCII码
- 示例: MAC=009001020304 → ID=303039303031303230333034

**心跳格式示例**: `0xA5 0x00 0x12 0X59 0X4A {硬件MacID} 0xBE`

**服务器返回**: 收到心跳包原封不动返回

**注意**: 设备连续3次收不到心跳信号会主动断开TCP连接，重新侦听或重连

### 6.2 心跳间隔修改

- 在配置软件的心跳使能板块修改间隔时间
- 需要2024年6月以后购买产品
- 配置软件需要V3.0.X以上版本

### 6.3 心跳内容修改

1. 心跳内容默认是设备MAC地址
2. 修改时需要设置为自定义ID
3. ID分为两类: 16进制ID / 字符型ID

**16进制ID**:
- 两个数表示一个字节
- ID需满足12位字节

**字符型ID**:
- 一个字符表示一个字节
- ID需满足12位字节

**配置报错**: 当修改ID小于12字节或大于12字节时会产生报错

## 9. CRC校验算法

### 9.1 方式一: 查表法

```c
const u8 chCRCHTalbe[] = // CRC 高位字节值表
{
    0x00, 0xC1, 0x81, 0x40, 0x01, 0xC0, 0x80, 0x41, 0x01, 0xC0, 0x80, 0x41,
    0x00, 0xC1, 0x81, 0x40, 0x01, 0xC0, 0x80, 0x41, 0x00, 0xC1, 0x81, 0x40,
    // ... (完整表格见原文档)
    0x00, 0xC1, 0x81, 0x40
};

const u8 chCRCLTalbe[] = // CRC 低位字节值表
{
    0x00, 0xC0, 0xC1, 0x01, 0xC3, 0x03, 0x02, 0xC2, 0xC6, 0x06, 0x07, 0xC7,
    0x05, 0xC5, 0xC4, 0x04, 0xCC, 0x0C, 0x0D, 0xCD, 0x0F, 0xCF, 0xCE, 0x0E,
    // ... (完整表格见原文档)
    0x41, 0x81, 0x80, 0x40
};

u16 LRC16(u8* pchMsg, u16 wDataLen)
{
    u8 chCRCHi = 0xFF; // 高CRC字节初始化
    u8 chCRCLo = 0xFF; // 低CRC字节初始化
    u16 wIndex; // CRC循环中的索引
    while (wDataLen--)
    {
        // 计算CRC
        wIndex = chCRCLo ^ *pchMsg++ ;
        chCRCLo = chCRCHi ^ chCRCHTalbe[wIndex];
        chCRCHi = chCRCLTalbe[wIndex];
    }
    return ((chCRCHi << 8) | chCRCLo);
}
```

### 9.2 方式二: 计算法

```c
u16 CRC16(u8 *data, u8 num) // 八位数组，个数
{
    u8 i, j, con1, con2;
    u16 CrcR = 0xffff, con3 = 0x00;
    for(i = 0; i < num; i++)
    {
        // 把第一个8位二进制数据与16位的CRC寄存器的低8位相异或
        con1 = CrcR & 0xff;
        con3 = CrcR & 0xff00;
        CrcR = con3 + data[i] ^ con1;
        // 把CRC寄存器的内容右移一位
        for(j = 0; j < 8; j++)
        {
            con2 = CrcR & 0x0001;
            CrcR = CrcR >> 1;
            if(con2 == 1)
                CrcR = CrcR ^ 0xA001;
        }
    }
    con1 = CrcR >> 8;    // 高字节
    con2 = CrcR & 0xff;  // 低字节
    CrcR = con2;
    CrcR = (con1 << 8) + CrcR;
    return CrcR;
}
```
