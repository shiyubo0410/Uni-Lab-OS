# 科星继电器网络协议技能包

## 概述

本技能包提供科星网络继电器产品的完整协议文档，支持2-48路继电器控制，包含MODBUS-RTU、MODBUS-TCP、科星私有协议和字符串协议等多种通信方式。

## 支持的协议

### 1. MODBUS-RTU
- 标准MODBUS协议
- 支持功能码: 01, 02, 03, 05, 06, 0F, 10
- CRC16校验

### 2. MODBUS-TCP
- 基于TCP的MODBUS协议
- 报文头 + RTU数据(无校验)
- 端口: 50000

### 3. 科星私有协议
- 场景指令集
- 支持2-48路全兼容
- 帧头: CC DD，结束: DD CC

### 4. 字符串协议
- JSON格式
- 支持485/232转发
- 易于调试

## 快速开始

### MODBUS-RTU控制第1路继电器

```
开:  01050000FF008C3A
关:  010500000000CDCA
```

### MODBUS-TCP控制第1路继电器

```
开:  00000000000601050000FF00
关:  000000000006010500000000
```

### 科星协议控制第1路继电器

```
开:  CCDDA3010000000000010000000000010000DDCC
关:  CCDDA3010000000000000000000000010000DDCC
```

### 字符串协议控制第1路继电器

```json
{"A01":110000,"res":"123"}
```
